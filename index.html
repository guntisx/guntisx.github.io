PiniTree is a universal web server featuring an integrated database and user management system, as well as a specialized ontology language and editor.
Key Features
• Universal Web Server: Distributed as a single precompiled and statically linked binary file for Linux or macOS. It starts directly from the command-line without complex installation steps.
• Ontology Language & Editor: Pini is an expressive ontology language similar to RDF, UML class diagrams, and Property Graphs, designed to support FrameNet-style natural language annotations.
